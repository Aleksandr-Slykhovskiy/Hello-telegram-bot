# Простой Telegram бот

Бот с кнопками для выбора вариантов.

## Как запустить:
1. Установите зависимости: `pip install -r requirements.txt`
2. Получите токен у @BotFather в Telegram
3. Запустите бота командой: `BOT_TOKEN="ваш_токен" python main.py`

Каждый пользователь должен получить свой токен у @BotFather!
